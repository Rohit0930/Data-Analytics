# Type C — Business Problem-Solving Cases

Use a diagnostic structure: clarify metric → segment → hypotheses → validate → recommend → measure.

## Practice cases
1. Airline bookings decline 15%.
2. Airline cancellation rate rises from 8% to 14%.
3. Revenue grows while NRR falls (FMG).
4. Customer count grows but revenue falls.
5. Retail sales rise while margin falls (Hummel).
6. Marketing leads grow but opportunities remain flat (Dell).
7. MQLs grow but sourced pipeline falls.
8. Campaign engagement improves but ROI declines (ITC).
9. Executive dashboard does not match source data (Xiaomi / Dell).
10. One region has significantly worse performance than others.
